# Code Web Chat — JetBrains and Firefox fork

Unofficial fork of Code Web Chat that adds a WebStorm/JetBrains plugin, a Node sidecar, and a Firefox build of the Connector browser extension.

> **Unofficial fork of robertpiosik/CodeWebChat by Robert Piosik. Not affiliated with or endorsed by the upstream author.** Upstream: [CodeWebChat/CWC](https://github.com/CodeWebChat/CWC). Attribution: [NOTICE.md](./NOTICE.md). Port details and the verification log: [PORTING.md](./PORTING.md).

## What this fork adds

| Component         | Path                            | Description                                                                                                                                             |
| ----------------- | ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| JetBrains plugin  | `apps/jetbrains`                | Kotlin plugin for WebStorm 2026.2+ (platform build 262+): tool window, Initialize, Apply Chat Response from Clipboard, Undo Last Changes, diff preview. |
| Sidecar           | `apps/sidecar`                  | Node process the plugin spawns. JSON-RPC 2.0 over stdio towards the IDE, and the local WebSocket server (`127.0.0.1:55155`) the Connector talks to.     |
| Core library      | `packages/core`                 | Host-agnostic prompt building and response parsing/apply/revert logic, shared by the sidecar and the editor.                                            |
| Firefox Connector | `apps/browser` (`dist-firefox`) | Manifest V2 build with a persistent background script, generated by `apps/browser/scripts/create-firefox-build.ts`.                                     |

## What is unchanged from upstream

| Area                                                                  | Status                                                                            |
| --------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| VS Code extension (`apps/editor`, package `gemini-coder`)             | Unchanged code paths, still built with `pnpm`                                     |
| Chrome Connector (Manifest V3, id `ljookipcanaglfaocjbgdicfbdhhjffp`) | Unchanged manifest and behaviour                                                  |
| WebSocket protocol, port, token and origin rules                      | Unchanged; the sidecar reuses them, so the same Connector works with both editors |

Guiding principles are unchanged: the plugin and the extension **initialize chatbots, they never scrape responses**, and the Connector's **Apply Response button is an alias for copy-to-clipboard** — nothing is extracted from the page.

## Install

### WebStorm 2026.2+ (build 262+)

1. Get `code-web-chat-0.1.0.zip` — build it with `./gradlew buildPlugin` (see below) or take it from `apps/jetbrains/build/distributions/`.
2. In WebStorm: **Settings → Plugins → ⚙ (gear icon) → Install Plugin from Disk…** and pick the ZIP.
3. Restart the IDE and open the **Code Web Chat** tool window.
4. Install Node.js (see [`.nvmrc`](./.nvmrc) for the pinned version); the plugin spawns the bundled sidecar with `node`.
5. If WebStorm does not inherit your shell `PATH`, set the interpreter in **Settings → Tools → Code Web Chat → Node path** (for example `/opt/homebrew/bin/node`).

The plugin descriptor declares `since-build 262` and no `until-build`, so it installs in WebStorm 2026.2.3 and later 262+ builds. If the VS Code extension already owns port `55155`, the sidecar reports the conflict instead of taking the connection over.

### Firefox (temporary load)

```bash
pnpm -C apps/browser build      # also generates dist-firefox/
pnpm -C apps/browser firefox:run
```

`firefox:run` is `web-ext run --source-dir dist-firefox --target firefox-desktop`, which installs the extension temporarily. Press `r` in that terminal after a rebuild to reload it.

### Firefox (self-distributed, signed)

```bash
WEB_EXT_API_KEY=... WEB_EXT_API_SECRET=... pnpm -C apps/browser firefox:sign
```

This is `web-ext sign --channel unlisted`, so the `.xpi` lands in `dist-firefox-signed/` and must be signed by Mozilla; get an API key pair at <https://addons.mozilla.org/developers/addon/api/key/>. The build carries a stable `browser_specific_settings.gecko.id`, which unlisted signing needs for updates. Never commit the key or secret. Details: [`apps/browser/README.md`](./apps/browser/README.md).

## Usage

1. Open the **Code Web Chat** tool window, press **Refresh**, and select the context files (or **Select all** / **Clear**).
2. Type optional instructions, pick the chatbot and edit format, then press **Initialize**. The sidecar builds the prompt and asks the Connector to autofill it in the chatbot tab.
3. When the answer is ready, press the response's **Apply** button (that copies it) and then **Apply response** in the tool window, or run **Code Web Chat: Apply Chat Response from Clipboard** (`Alt+Shift+A`). Each changed file is shown in a diff first (Apply / Skip / Cancel all) before anything is written.
4. Run **Code Web Chat: Undo Last Changes** (`Alt+Shift+Z`) to revert the files touched by the last apply.

The Connector's own Apply button also triggers the apply automatically, as it does in VS Code.

## Build from source

Requirements: JDK 21 on `JAVA_HOME` or `PATH`, Node.js, and pnpm (the workspace pins its version in `package.json`).

```bash
pnpm install --frozen-lockfile     # workspace dependencies
pnpm --filter @cwc/sidecar build   # writes apps/sidecar/out/sidecar.js
npx jest                           # 18 suites, 206 tests
```

Type checks that were run:

```bash
cd apps/editor && npx tsc --noEmit
npx tsc -p apps/sidecar/tsconfig.json --noEmit
```

JetBrains plugin — the Gradle 9.9.0 wrapper is committed, so no system Gradle is needed:

```bash
cd apps/jetbrains
./gradlew build            # compile, instrument, jar, check (Kotlin warnings are errors)
./gradlew buildPlugin      # build/distributions/code-web-chat-0.1.0.zip
```

The `buildPlugin` ZIP is self-contained: `code-web-chat/lib/*.jar` plus `code-web-chat/sidecar/sidecar.js`. `buildSearchableOptions` is disabled because it boots a whole IDE to index the settings page, which fails without a display.
